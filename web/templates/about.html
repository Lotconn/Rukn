The Project

The aim is to create a single Athan application that will run under as many devices and operating systems as possible.

As well as achieving that goal, the application's sourcecode will be opensource, and the application will cost nothing and will contain no advertisements, tracking or any other horrible things.

Anybody willing to contribute to the project is very welcome, please contact me to discuss where help is needed.


Contributors

Qt-Project: Munadi uses the cross-platform Qt Framework for the GUI and other functions.

BatoulApps: Munadi uses adhan-js from BatoulApps to do the calculations.

GitLab: All sourcecode is now hosted at GitLab.
