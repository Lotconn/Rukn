Munadi 26.02

Bug fixes, minor UI changes and new installer

    Notable bug fixes
  • Fix 'System' theme doesn't follow system
  • Fix muted athan plays on next start
  • Fix time not updated on tooltip
  • Allow exiting fullscreen during first onboarding
  • Prevent texts running into each other and overflowing around
  • Updates to android build
    New changes
  • Improve the looks of the main page
  • Monochrome tray icon
  • Two more built-in athans including fajr athan
    The self-extracting installer
  • Munadi can now be installed using a self-extracting installer. No need for downloading loads of dependencies, just make it executable (chmod +x) and run the interactive installer. That's it! If you want to try it out, the latest version of the installer is available at https://gitlab.com/munadi/munadi/pkg/makeself
